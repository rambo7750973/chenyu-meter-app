# 辰域电表配网计费APP

一个用于与辰域智能电表进行通信、配置网络连接和计费管理的Android应用。

## 功能特性

### 1. 设备配网
- BLE蓝牙扫描和连接
- 设备自动发现
- 网络配置

### 2. 实时监控
- 实时功率、电压、电流显示
- 用电量统计
- 设备在线状态

### 3. 计费管理
- 支持阶梯电价、分时电价、固定电价
- 自动计算电费
- 账单生成和支付状态

### 4. 数据统计
- 日/月/年用电量统计
- 费用统计
- 用电趋势分析

## 技术架构

- **语言**: Kotlin
- **UI**: Jetpack Compose + Material 3
- **架构**: MVVM + Clean Architecture
- **依赖注入**: Hilt
- **数据库**: Room
- **BLE通信**: Android BLE API
- **异步**: Kotlin Coroutines + Flow

## 环境要求

- Android Studio Hedgehog (2023.1.1) 或更高版本
- JDK 17
- Android SDK 34
- Kotlin 1.9.20

## 安装步骤

1. 克隆项目
2. 用Android Studio打开项目
3. 等待Gradle同步完成
4. 连接Android设备或启动模拟器
5. 点击Run按钮运行应用

## 权限说明

应用需要以下权限：
- 蓝牙权限：用于扫描和连接电表设备
- 位置权限：BLE扫描需要
- 网络权限：用于数据同步
- 存储权限：用于数据导出

## 配置说明

### 电价配置
在设置中可以配置：
- 阶梯电价：按用电量分段计费
- 分时电价：按时间段计费
- 固定电价：统一电价

### 设备配对
1. 打开应用，点击"添加电表"
2. 应用会自动扫描附近的BLE设备
3. 选择辰域电表设备进行配对
4. 配对成功后即可读取数据

## 注意事项

1. **协议文档**：本应用假设没有辰域电表的通信协议文档，实现了通用的BLE通信框架。实际使用时需要根据电表的具体协议进行调整。

2. **设备兼容性**：不同型号的辰域电表可能使用不同的通信协议，需要针对性适配。

3. **数据解析**：示例代码中的数据解析逻辑是简化的，实际使用时需要根据真实协议实现。

4. **安全性**：生产环境中需要实现数据加密和用户认证。
